# Reference research, 2026-09-18

Read the official [development site](https://www.hauntedchocolatier.net/), [FAQ](https://www.hauntedchocolatier.net/faq/), [screenshots page](https://www.hauntedchocolatier.net/media/), [combat discussion](https://www.hauntedchocolatier.net/2021/10/30/combat-shields-stuns-my-approach/) and [chocolate-making discussion](https://www.hauntedchocolatier.net/2025/05/10/intuitive-chocolate-making/). The latest visible development post is dated August 30, 2026; the June 25 post discusses recipe-book iteration. These are design references only. No assets from those pages entered the repository.

Working interpretation: keep frequently used menus legible and quick to operate; make shields a deliberate choice; connect exploration ingredients to chocolate. Warm windows against a cool nocturnal setting guide this project's own temporary artwork. This is an interpretation of broad qualities, not a reconstruction of the referenced game.

The [Phaser release page](https://phaser.io/download) now advertises Phaser 4. This project follows the specified stable Phaser 3 baseline, whose registry version is 3.90.0.

[MDN's WebRTC signaling documentation](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Signaling_and_video_calling) explains that signaling is separate from the peer connection. This project exchanges the gathered offer and answer through local QR/manual pairing. The design does not promise connectivity across isolated networks.
