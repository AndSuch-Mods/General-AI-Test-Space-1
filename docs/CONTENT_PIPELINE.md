# Content pipeline

The master content schemas and validation requirements are in TECHNICAL_ARCHITECTURE.md. New content needs a stable ID, scope where relevant, valid references, provenance and a content-ledger entry. Build-time validation must expand whenever a new data family is added. The current arrival data declares personal or shared_world explicitly.

Temporary original assets are recorded in CONTENT_LEDGER.md. Their source generators stay in the repository so replacement can preserve dimensions and interaction anchors. Phase 11 must replace geometry with coherent original pixel art and expressive portraits, then add original audio. Do not call the current temporary visual set final.
