# CM2109 Commissioning Checklist

Mobile-first field checklist for Core Machine 2109 commissioning.

- Power Test
- Parts Installation
- Programming (primary)
- HMI (secondary)
- Persistent local progress
- Clear checked → recoverable archive
- PWA / iOS Add to Home Screen support
- Offline caching through a service worker

The checklist content is derived from the CM2109 controls drawings and the current CM2109 PLC/HMI day-of packages.
